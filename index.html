    It started when a fake check fooled me

    A fake "I'm not a robot" page tricked me. So I built ClickFix First Aid: a free, open-source extension for Chrome and Edge that stops these pages from putting malware commands on your clipboard. Nothing leaves the browser.

    • 248 automated tests, including real-browser end-to-end
    • CI on Linux and Windows with a Microsoft Defender scan
    • Reproducible releases with SHA-256 checksums
    • Published on Microsoft Edge Add-ons after Microsoft's certification review
